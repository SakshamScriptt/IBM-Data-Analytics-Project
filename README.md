# Customer Churn Analysis & Prediction using AI

**Author:** Saksham Pratap
**Institution:** JSS Academy of Technical Education, Noida
**Program:** AICTE | IBM SkillsBuild Data Analytics with AI Internship

## Project Overview
This project involves analyzing a telecommunications customer dataset to understand the key factors that lead to customer churn. After performing Exploratory Data Analysis (EDA) to find data trends, a Machine Learning AI model (Random Forest Classifier) is trained to predict whether a specific customer is likely to cancel their service. 

## Dataset Link
The data used is the open-source IBM Telco Customer Churn dataset.
Link: [IBM Telco Customer Churn Dataset](https://raw.githubusercontent.com/IBM/telco-customer-churn-on-icp4d/master/data/Telco-Customer-Churn.csv)

## Technologies Used
* **Programming Language:** Python 3
* **Data Manipulation:** Pandas, NumPy
* **Data Visualization:** Matplotlib, Seaborn
* **Machine Learning / AI:** Scikit-Learn (Random Forest)

## Setup and Run Instructions
1. Ensure Python is installed on your system.
2. Open your terminal or command prompt.
3. Install the required dependencies by running: 
   `pip install -r requirements.txt`
4. Run the Python script using:
   `python SakshamPratap_CustomerChurn.py`
5. The console will display the dataset shape, model training progress, and the final AI model accuracy and classification metrics. It will also generate a PNG file showing the churn distribution.
